# P175 同分辨率软标签 KD (T=1) — 阶段报告（判死 / 负向）

> 日期：2026-10-31｜分支：experiment/blank-governance-p0-p38｜状态：负向，用户 kill 停训（ep45/55）
> 关联：P174(同分辨率 T=4, 判死) 的温度消融；P172(跨分辨率, 判死)；P167-wh0(无头基线)

## 1. 背景与动机
P174（同分辨率软标签 KD, T=4）已判死，但其负向根因推测是 "T=4 软化削平教师判别尖锐度，与「学生需更 sharp」主诊断相悖"。
为隔离 "温度" 这一单一变量，用户决策开 **T=1 消融**（P175）：其余配置与 P174 完全一致（同教师缓存、无 word_head、λ_ctc=λ_kd=1.0、BLANK_BIAS=1.0、[35,45]@55），仅把 T=4.0 → T=1.0。
机理意图：T=1 不软化，教师应把 "判别尖锐度" 直接传给学生，若 T=4 真是冤枉，则 T=1 应显著优于 T=4，并有望逼近甚至低于无头基线 55.38% / 有头 P150 53.73%。

## 2. 方法
- 学生 `p175_train_distill_t1.py`：VAC@160（35.25M，from scratch，**无 word_head**），沿用 P174 教师缓存 `artifacts/cache/p174_teacher/`（T_raw==canonical_T 对齐零误差）。
- λ_ctc=λ_kd=1.0，T=1.0，lr=1e-4 / wd=1e-4 / batch=2 / MultiStepLR[35,45]@55，BLANK_BIAS=1.0。

## 4. 公平性核查（关键）
P175 与 P174 同为 **无 word_head** VAC@160。两个公平基线：
- **P167-wh0（无头、无 KD）** 跑满 55ep，best **55.38%**（ep50），平台 ~55.4–56.4。
- **P150（有头）** best **53.73%**。

### 4.1 P175 vs P167-wh0（无头 vs 无头，公平）
ep36–45 逐 epoch 配对（P175 − P167-wh0）：
```
36:+3.42 37:+2.67 38:+2.92 39:+3.66 40:+2.11 41:+3.06 42:+3.41 43:+3.31 44:+3.00 45:+3.48
```

- 两平台完全不重叠（P175 58.97–60.13 vs P167-wh0 55.38–56.40），方向 10/10 一致 ⇒ 即便点 SNR 略 <2，仍为**稳健负向**：**T=1 软标签 KD 把无头学生从 55.38% 拖累到 58.97%（+3.6pp）**，KD 在此是负作用而非增益。

### 4.2 P175 vs P150（有头天花板）
best 58.97 vs 53.73 = **+5.24pp**。无头本就比有头差（head 是关键正则器），P175 既无 head 又加 KD，双重落后。

## 5. 结论：负向，判死
- **T=1 是软标签 KD 的正确温度（推翻 P174 的「T=4 冤枉」假设成立），但即便 T=1，软标签 KD 在 CE-CSL from-scratch VAC 上仍为负向**——它让无头学生比「不蒸馏的无头基线」还差 3.6pp。
- 根因：零样本 TFNet@160 教师自身**峰锐度仅 0.624**（官方 0.864），p_blank≈0.875 全局占优。T=1 蒸馏等于把教师这份「模糊 + blank 偏置」直接灌给学生，而非其判别知识；学生学的是更糊、且 blank 偏重的分布，与「学生需更 sharp」主诊断相悖。gen率升（72%）但 WER 仍差 = "生成更多但错更多"，与 P174 同象。
- **word_head 才是让 P150 从 ~59 继续降到 53 的关键使能器**：去掉头后（P175 / P167-wh0）无论加不加 KD 都卡在 ~55–59。KD 无法补偿缺失的头正则。
- 验收线：强成功 dev<36.81（教师零样本）完全不可达；终值预计 ~59%，连无头基线 55.38 都达不到。
